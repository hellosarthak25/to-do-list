# to-do-list
Developed a responsive To-Do List application using HTML, CSS, and JavaScript with dynamic DOM manipulation, local storage, and intuitive user interface design.
## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Responsive user interface
- Dynamic DOM manipulation

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## Project Structure

```
to-do-list/
│── index.html
│── style.css
│── script.js
```

## Future Improvements

- Edit tasks
- Local Storage support
- Dark mode
- Task categories
- Due dates
